# Onore Cafe — online ordering (PWA)

Απλή, δωρεάν σελίδα παραγγελίας για το **Onore Cafe, Κυπαρισσία**.
Ο πελάτης διαλέγει από το μενού, επιλέγει **Παραλαβή ή Delivery**, και η παραγγελία
ανοίγει **έτοιμη στο WhatsApp** του καταστήματος. Πληρωμή στην παράδοση. Χωρίς προμήθειες.

Εγκαθίσταται στο κινητό σαν εφαρμογή (PWA / «Προσθήκη στην αρχική οθόνη»).

## Ρυθμίσεις (μόνο ένα αρχείο)
Στο `config.js`:
- `whatsapp` — ο αριθμός WhatsApp του Onore σε διεθνή μορφή (π.χ. `30697xxxxxxx`).
- `deliveryFee` — χρέωση delivery σε € (0 = δωρεάν).
- `minOrder` — ελάχιστη παραγγελία σε € (0 = χωρίς).

Το μενού (προϊόντα/τιμές) στο `config`-free αρχείο `menu.js`.
